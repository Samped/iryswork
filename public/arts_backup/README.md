# Artworks Folder

Place your artwork images in this folder and update `artworks.json` to display them in your portfolio.

## How to Add Artworks

1. **Add your image files** to this folder (e.g., `my-artwork.jpg`, `design-1.png`)

2. **Update `artworks.json`** with your artwork information:

```json
[
    {
        "id": "art-1",
        "title": "My Amazing Artwork",
        "description": "A detailed description of your artwork and the story behind it.",
        "image": "my-artwork.jpg",
        "date": "2024-01-15"
    },
    {
        "id": "art-2",
        "title": "Another Piece",
        "description": "Another beautiful creation.",
        "image": "design-1.png",
        "date": "2024-01-20"
    }
]
```

## Supported Image Formats

- JPG/JPEG
- PNG
- GIF
- WebP

## Tips

- Use descriptive filenames
- Keep image sizes reasonable (under 5MB recommended)
- Write engaging descriptions to tell the story of each piece
- Use dates in YYYY-MM-DD format

Your artworks will automatically appear in the Arts & Designs section of your portfolio!
